Herencia

La herencia es un mecanismo de la Programación Orientada a Objetos (POO) que permite crear clases nuevas a partir de clases preexistentes.

Usando este concepto, las clases nuevas pueden tomar (heredar) atributos y métodos de clases anteriores. Incluso pueden modificarlos para modelar una nueva situación.

La clase que aporta los métodos y atributos para heredar se la denomina clase base, superclase o clase padre, y a las que se construyen a partir de ella clases derivads, subclases o clases hijas.

Herencia Simple 

Tiene lugar cuando una clase derivada (subclase) hereda atributos y métodos de una única clase base(superclase)

Herencia Multiple

La herencia múltiple ocurre cuanod una subclase deriva de dos o más clases base. 

Clases Abstractas
¿Qué son?
Las clases abstractas son "moldes" que definen métodos y propiedades, pero no se pueden instanciar directamente. Solo se usan para crear subclases.

Propósito principal:

Evitar la duplicación de código al proporcionar atributos y métodos comunes a todas las subclases.

Definir una interfaz común que las subclases deben seguir.

Características clave:

No se pueden instanciar: Solo sirven como base para otras clases.

Métodos abstractos: Pueden tener métodos sin implementación (solo declarados), que deben ser implementados por las subclases.

Obligatoriedad: Las subclases deben implementar todos los métodos abstractos para poder ser utilizadas.


Polimorfismo

El Polimorfismo es un de los pilares de POO. El termino tiene origen en las palabras poly(muchos) y morfo (formas), y aplicado al a programación hace referencia a que los objetos pueden tomar difrentes formas.
Esto significa que objetos de difertens clases pueden ser accedios utlizando la misma interfaz, mostrando un compartaimento distinto(tomando diferentes formas) Según como sean accedidos.

Colaboración de Clases

se manifiesta como la posiblidad de utilizar en una clase objetos que son instancias de una clase diferente. Este mecanismo potencia el alacance que tiene la Programación Orientada a Objetos. Facilitando aún más el desarrollo de soluciones a problemas complejos sin necesidad de escribir codigo extenso o dificiles de leer.

Atributos de clase
Los atributos de clase a diferecnai de los atributos de instancia, son compartidos por todos los objetode dicha clase. Los atriubtos de clase se definen dentro de la case pero no fuera de sus métodos.

Composición

La composición es uno de los conceptos fundamentales de la POO. Tiene lugar cuando una clase (clase "que tiene") hace referencia a uno o más objetos de otras clases (clases "que son parte de"), como una variable de instancia.

Mediante la composición solo se puede utilizar la otra clase(la "que es parte de")
