Definición Vue:

Vue.js es un framework progresivo de JavaScript de código abierto, creado por Evan You en 2014. Se centra en la capa de visualización y facilita el desarrollo de interfaces web interactivas, permitiendo una fácil integración con otras librerías o proyectos front-end.

Dom-virtual

Vue utiliza un DOM virtual, que es una réplica del DOM real en estructuras de datos JavaScript. Los cambios se hacen en esta réplica y luego se comparan con el DOM original para actualizar solo lo necesario. Esto mejora el rendimiento y optimiza las actualizaciones, haciéndolas más rápidas y menos costosas. El sistema de renderizado de Vue se basa en este concepto, que fue introducido por React y luego adoptado en otros frameworks.

¿Qué es el renderizado?

El termino renderización, se usa pra referirse el proceso de generar o representar algo en la pantalla. Los resultados de mostrar dicho modelo puden llamarse render. En una web el renderizado ocurre cuando se visita la página y su contenido se representa en la pantalla

¿Que es la reactividad en vue?

Reactividad es cuando la vista de la aplicacíon cambia cuando os valores reactivos dentro de esas cambian su valor'



NOTAS: Conceptos Claves

Data Binding. La función de data binding ayuda a manipular o asignar valores a atributos HTML, cambiar el estilo, asignar clases con la ayuda de la directiva de enlace llamada v-bind disponible en Vue

Event Handing: v-on es el atributo agregado a los elementos DOM para escuchar los eventos en VUE.js

Computed Properties: Esta es una de las caracteristicas más importantes de Vue. Ayuda a escuchar los cambios ralizaados en los elementos de la interfaz de usuario y realiza los cálculos necesarios. No hay necesidad de codificación adicional para este fin.

Templates: Vue.JS proporciona plantillas basadas en HTML que unen el DOM con los datos de la instancia de Vue. Vue compila las plantillas en funciones virtuales DOM Render. Podemos hacer uso de la plantilla de las funciones de render y para hacerlo tenemos que remplazar la plantilla con la función de render.

Directives: Vue.JS tiene directivas integradas como v-if, v-else, v-show, v-on, v-bind, y v-model, que se utilizan para realizar varias acciones en la interfaz.

Watchers: Los Watchers se aplican a los datos que cambian. Por ejemplo, elementos de input en formularios. Aquí, no tenemos que agregar ningún evento adicional. Los Watcheers se encargan de manejar cualquier cambio de datos haciendo que el código sea simple y rápido.


Propiedades Computadas

Es importante saber que los campos computados no pueden recibir valores mediante parámetros desde fuera de la función. Si es necesario parar un valor, en lugar de un campo computado se debe crear un metodo

Creción de Componentes

Los componentes son una de las caractersticas importantes de Vue.js que ayudan a crear elementos personalizados, que se pueden reutilizar en HTML. El nombre asigando a las etiquetass ser remplazado por el codigo del "Templete" escrito en la creación del componentes.

Watchers

Un watcher (observador) en Vue es una característica especial que nos permite obasrvara algunos datos y realizar acciones especificas  cuando cambian.
Por ejemplo, elementos input en formularios. Los watchers se encargan de manejar cualquier cambio de datos haciendo que el codigo esa simple y rapido.

MVC Y MVVM

De manera simir al MVC, el MVVM o modelo-vista-modelo de vista es un patrón de arquitectura de software que se caracteriza por desacoplar lo máximo posible la interfaz del utario de la lógica de la aplicación.

Diferencias entre MVVM y MVC 

MVVM realiza la sinconización automática de la vista y el modelo, es decir, cuando cambia el atributo del modelo, no necesitamos operar manualmente el elemento dom para cambiar la visualización de la vista, la capa de la vista cambiará automaáticamente

Puntos Clave del patrón MVVM:

1) El usuarrio interactúa con la vista.
2) View y ViewModel tienen una ralación de uno a uno, lo que significa que una vista spñp se íede asignar a un ViewModel.
3) View contiene una referncia a ViewModel, pero View no tiene información sobre el modelo.
4) Existe una relación de enlace de datos bidireccional entre View y ViewModel.
